# Phase 05a: Video Prep (write the video prompt for each segment)

> **Non-lipsync generation path**: this PHASE.md describes the **asset_reference** path (Seedance 2.0 — non-lipsync prompts name refs via `@assetN`/`@imageN`). If `creative_proposal.model_primary` is **not** a Seedance 2.0 variant, non-lipsync segments are on the **keyframe** path — read `docs/non_seedance_path.md` (Phase 05a): non-lipsync segments then drop `@assetN`/`@imageN`, carry source refs, leave keyframes empty for Phase 05b, and set `shot_count`. Lipsync segments are identical on both paths.

## Role Division

- **Main Agent**: spawn sub-agent -> validate -> write draft -> SELF-CHECK (verify prompts) -> route (no lipsync segments AND asset_reference path -> finalize and proceed to Phase 06; otherwise -> do not finalize, proceed to Phase 05b)
- **Sub-agent**: in a clean context, read the prompt template + video-generation skill, then **batch** write the prompt + assign model + map **non-lipsync segment** references[] for every segment (lipsync segment keyframes are left for Phase 05b to generate)

## Goal

Write the prompt + model + duration for feeding to the video model for every segment in `creative_proposal`. **Non-lipsync segments** on the **asset_reference path** (Seedance 2.0) get their references mapped (character/location/prop; ARK was registered in Phase 04); on the **keyframe path** (any other model) they instead carry source refs + empty keyframes per `docs/non_seedance_path.md`. **Lipsync segments** only get shot-by-shot prompt + audio + `model=dlai2v_pro`; keyframes are generated by Phase 05b using `gpt-image-2`, split, uploaded, and backfilled. Output is `video_prep` (draft; finalized in this phase only when there are no lipsync segments AND the non-lipsync path is asset_reference, otherwise handed off to 05b to finalize). segments[] must be strictly index-aligned with `creative_proposal.segments[]`.

## Required Inputs

- `creative_proposal` / `reference_list` / `visual_config` (promoted)
- `ARTIFACT_CONTRACT_PATH`

## Preflight Reads (Main Agent)

1. Read `schemas/video_prep.schema.json`
2. Read `phases/05a-video-prep/templates/video_prep.minimum.json`
3. Read promoted `creative_proposal` / `reference_list` / `visual_config`

> The main agent does not read the prompt template / video-generation skill field details -- that is the sub-agent's job.

## Core Principle: Model Fields Follow the video-generation Skill

Which fields / placeholders / frame protocol each segment needs -- **is entirely determined by the current spec for `segment.model` in `video-generation/SKILL.md`** (lipsync segments additionally reference `lipsync/SKILL.md`). This file does not restate specific model fields. **How to write** the prompt follows `prompt_authoring.md` (lipsync in section 1 / non-lipsync in section 2).

**Lipsync segment model is always `dlai2v_pro`** (dlai2v_pro supports both single-frame image_url and multi-frame keyframes list; this skill uses dlai2v_pro exclusively for lipsync, not dlai2v). Non-lipsync segment model = `creative_proposal.model_primary`.

## Step 1 -- Sub-agent Batch Write Prompts

Launch a clean-context sub-agent task:

```
Task: Write prompt + assign model for every segment in creative_proposal; map references[] for non-lipsync segments. Output video_prep.

Required reads:
1. video-generation/SKILL.md from <available_skills> -- which fields / references / placeholders each segment.model requires
2. lipsync/SKILL.md from <available_skills> -- lipsync segment (dlai2v_pro) prompt format
3. phases/05a-video-prep/references/prompt_authoring.md -- prompt writing template + duration rounding
4. promoted creative_proposal / reference_list / visual_config
5. **If model_primary is not a Seedance 2.0 variant** (non-lipsync segments are on the keyframe path): docs/non_seedance_path.md (Phase 05a) -- it overrides the non-lipsync handling in item 3 below (no @assetN/@imageN, attach source refs, leave keyframes empty, set shot_count)

Additional instructions from main agent: model_primary = <value>; non-lipsync generation path = <asset_reference | keyframe>; any visuals / shots called for by the creative brief (if applicable).

For each segment (in creative_proposal.segments[] order, index-aligned):

1. shot_count + prompt (**first determine shot count per prompt_authoring section 0**: non-lipsync approx ceil(segment_duration / 3); lipsync by distinct framing, see below). Write the shot count into the segment's **`shot_count` field**, and ensure the number of explicit `Shot 1/2/...` entries in the prompt matches `shot_count`:
   - Non-lipsync segment -> section 2 (DP shot-by-shot, derived from segment.description + brief). `shot_count` = number of shots in the segment (informational).
   - Lipsync segment -> section 1 (lip-sync driven): **prepend this fixed prefix at the beginning**: "Follow the character and visual style from the input image. All shots should continue in motion\n\nsync motion and lips to the audio.", then write explicit `Shot 1 / Shot 2 / ...`, **every shot must include `sings/speaks with perfect lip synchronization` + body motion** (N shots means writing it N times), singer in close-up / medium shot, looking into camera. **Do not write cuts / transitions, do not add visual style, do not write `@assetN/@imageN/@audioN` placeholders** (framing changes rely on keyframe interpolation; keyframes already lock style / scene / costume). **`shot_count` = Phase 05b keyframe count**; 05b reads it directly (does not parse the prompt); **calculated by distinct framing**: body motion / emotion changes within the same framing do not start a new Shot; only an actual framing change increments +1; continuous single framing -> `shot_count=1`, capped at 4.

2. model: non-lipsync = model_primary; lipsync = dlai2v_pro.

3. references[]:
   - Non-lipsync segments **(asset_reference path — Seedance 2.0)**: map from reference_list -- **segments with characters = the 2-panel character reference sheet for that character's corresponding look (one sheet, includes clear face + full body; for multi-look, select the corresponding look)**; also map in that segment's location / prop refs. **All refs must be named in the prompt via `@imageN` / `@assetN`** (including scenes / props, not just characters); get URLs from reference_list (latest). Placeholders follow `dl generate-video -h` current rules: `@imageN = image_urls[N-1]`, `@assetN = ark_asset_ids[N-1]`, `@audio1 = reference_audio_url`; **do not use global reference_list numbering, and do not mix asset/image into a single visual numbering scheme**. **Live-action characters (character reference sheet) -> `ark_asset_id` (`@assetN`, asset-only; do not also put the same URL into `image_urls`); scenes / props -> image_urls (`@imageN`)**. Audio comes from segment.audio_url. **references[] image count follows the limit for `segment.model` in video-generation/SKILL.md** -- if over the limit, drop the least critical / most easily described in text (remove from references[], add text description in prompt to compensate); keep character 2-panel character reference sheets and other identity/structure references that are hardest to describe in text; regardless of whether images are dropped, all appearing characters / locations must be named in the prompt.
   - Non-lipsync segments **(keyframe path — any other model)**: per `docs/non_seedance_path.md` -- write the shot-by-shot prompt with **NO `@assetN`/`@imageN`** (identity/scene are carried by the keyframe); attach the 2-panel character reference sheet + location/prop as **source refs** (role=character_asset/location_asset/prop_asset) for Phase 05b; **leave keyframes empty** (05b backfills role=keyframe); set `shot_count` = distinct shot compositions.
   - Lipsync segments: fill **audio** ({role: audio_slice, url: segment.audio_url}) + **the 2-panel character reference sheet for appearing characters + scene location source ref** (role=character_asset / location_asset, mapped from reference_list; these are **materials for Phase 05b to generate keyframes**, not for Phase 06 -- see below). **Leave keyframes empty** -- Phase 05b will backfill with role=keyframe (do not fabricate keyframe URLs yourself).
   > **source ref vs keyframe**: character_asset / location_asset in lipsync segment references are **inputs for 05b image generation**; the 1-4 shot keyframes generated by Phase 05b (role=keyframe, ref_id `keyframe1..N`) are **what gets fed to dlai2v_pro in Phase 06**. Phase 06 for lipsync segments **only passes lipsync prompt + keyframes (+audio), not raw character / scene refs** (they are already baked into the keyframes).

4. duration: round up to the nearest whole second (see prompt_authoring section 3). aspect_ratio = visual_config.aspect_ratio; resolution = visual_config.resolution.

Output the complete video_prep JSON with segments[] strictly index-aligned to creative_proposal.segments[].
```

> **Batch execution**: one task writes all segments.

## Step 2 -- Main Agent Validation (lean)

1. `segments.length == creative_proposal.segments.length`, index-aligned
2. Every segment `prompt` is non-empty + follows the corresponding prompt_authoring template (including section 0 shot splitting). **Lipsync segments: has the fixed prefix at the beginning, every shot includes `perfect lip synchronization`, no cuts / transitions, no visual style, no `@assetN/@imageN/@audioN` placeholders**; **Non-lipsync segments (asset_reference path — Seedance 2.0): visual style capped at 15 words, and all references being fed (including characters / scenes / props) are named in the prompt with correct channel numbering `@assetN` / `@imageN`; on the keyframe path: visual style capped, but NO `@assetN`/`@imageN` (identity carried by the keyframe — see docs/non_seedance_path.md)**
3. Every segment `model` is compliant: non-lipsync = model_primary; lipsync = dlai2v_pro
4. **Every segment has `shot_count`** (integer >= 1, matching the number of explicit `Shot 1/2/...` in the prompt); **lipsync segment `shot_count` must be in [1,4]** (05b reads it directly to set `target_keyframe_count`); >4 or mismatch with prompt shot count -> send back for rewrite
5. Non-lipsync segment references[] **(asset_reference path — Seedance 2.0)**: segments with characters have **the 2-panel character reference sheet for that character's corresponding look (one sheet)** + that segment's location / prop + audio; reference URLs taken from the latest reference_list; **live-action character reference sheets with ark_asset_id must be asset-only (@asset); location / prop must remain image-only (@image)**; **all appearing characters / locations are named in the prompt (cannot just attach a URL without mentioning it)**; **references[] image count <= segment.model limit (per video-generation/SKILL.md); over-limit images have been dropped and replaced with text descriptions**. **(keyframe path — non-Seedance: validate per `docs/non_seedance_path.md` instead -- prompt has no `@assetN`/`@imageN`, keyframes empty pending 05b, source refs present, shot_count in [1,4].)**
6. Lipsync segment references[]: has audio + appearing characters' **2-panel character reference sheet** / scene source ref (role=character_asset/location_asset, for 05b image generation); keyframe is empty (to be filled by 05b with role=keyframe, ref_id keyframe1..N)

Any failure -> have the sub-agent fix that segment.

## Step 3 -- Write Draft + SELF-CHECK (Verify Prompts) + Routing

First, `dl artifact write` to save video_prep as a draft (not promoted):

```bash
cat <<'EOF' | dl artifact write --slot=video_prep --content-type=application/json --content-file=-
{ "segments": [ ... ] }
EOF
```

Then read back the **actual content of the draft** -- one Card per segment (prompt / model / references / QA) -- and self-check it. Lipsync segments note that keyframes are pending 05b generation:

```
=== Video prompt done (<N> segments, primary model: <model_primary>, resolution: <res>) ===

[Card] seg_01 - 0.00-9.00s - <model_primary> - non-lipsync
  Prompt: <full prompt>
  References: [thumb] character reference sheet (face+body) + [thumb] location  [audio] audio_slice
  QA: pass
[Card] seg_02 - 9.00-13.50s - dlai2v_pro - lipsync
  Prompt: <shot-by-shot singing prompt>
  References: [audio] audio_slice  - keyframe -> generated in Phase 05b
  QA: pass
...
```

Self-check the prompts against the template + segment plan (each prompt follows prompt_authoring, model is compliant, references map correctly), then resolve each case yourself:
- **A specific segment prompt / model is wrong** (seg_NN) -> sub-agent rewrites.
- **Overall direction is wrong** -> go back to Phase 02 to revise segments.
- **Pass** -> **route**:
  - **No lipsync segments AND asset_reference path (Seedance 2.0)** -> finalize video_prep directly in this phase (draft is already complete), proceed to Phase 06:

```bash
dl artifact finalize --slot=video_prep --mode=verify_and_promote \
  --contract='<ARTIFACT_CONTRACT_PATH>'
```

  - **Has lipsync segments, OR keyframe path (non-Seedance model)** -> **do not finalize** (keyframes have not been generated yet), proceed to Phase 05b (it generates keyframes for lipsync and/or keyframe-path non-lipsync segments, backfills, then finalizes).

When fixing a prompt / going back to Phase 02: sub-agent makes fixes and `dl artifact write` overwrites the draft, return to Step 3 to re-verify.

## Do Not Proceed Unless

- `segments.length == creative_proposal.segments.length`
- Every segment `prompt` is non-empty + matches the template (including section 0 shot splitting); `model` is compliant (non-lipsync=model_primary / lipsync=dlai2v_pro)
- **Lipsync prompt**: has the fixed prefix, every shot includes `perfect lip synchronization`, no cuts / transitions, no visual style, no `@assetN/@imageN/@audioN`
- **Non-lipsync prompt (asset_reference path — Seedance 2.0)**: visual style <= 15 words; all references being fed (including characters / scenes / props) are named in the prompt with the correct channel numbering `@assetN` / `@imageN`. **(keyframe path: visual style <= 15 words, no `@assetN`/`@imageN` — see docs/non_seedance_path.md)**
- Every segment has `shot_count` (matching the explicit Shot count in the prompt); lipsync segment `shot_count` must be in [1,4]
- Non-lipsync segments with characters have references = **the 2-panel character reference sheet for that character's corresponding look (one sheet)** + applicable location/prop + audio; URLs taken from the latest reference_list; **(asset_reference path)** live-action character reference sheets with ark_asset_id are asset-only, location/prop are image-only **(keyframe path: these are source refs for Phase 05b, no ark_asset_id — see docs/non_seedance_path.md)**
- Lipsync segment references have audio + appearing characters' **2-panel character reference sheet** / scene source ref (for 05b keyframe generation); keyframe left empty for 05b
- duration has been rounded up to the nearest whole second
- SELF-CHECK on prompts passed
- **No lipsync segments AND asset_reference path**: video_prep is finalized; **otherwise (has lipsync segments, or keyframe path)**: video_prep remains as draft, handed off to Phase 05b (not finalized in this phase)
