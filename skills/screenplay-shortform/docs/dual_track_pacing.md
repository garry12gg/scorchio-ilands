# Dual-Track Pacing (Persistent Rule)

> A short film's tension comes from deliberate misalignment between **external plot pace** and **internal emotional pace**.
> Revisit this file in Phases 03 / 04 / 05 / 06.

## 1. External Plot Pace

| Intensity | Expression |
|---|---|
| **tight** | dense events, fast cuts, multi-person dialogue, chase, confrontation, reveal |
| **medium** | active but not compressed; scene goal advances steadily |
| **loose** | daily routine, solitary moment, transition, landscape, silence |

Rule of thumb: after each high-intensity plot beat, include a breathing beat so the audience can process it.

## 2. Internal Emotional Pace

| Intensity | Expression |
|---|---|
| **heavy** | confession, betrayal, loss, fear, ecstasy, despair |
| **medium** | pressure is present but controlled |
| **light** | banter, casual talk, small humor, quiet companionship |

## 3. Misalignment Is Advanced Storytelling

| Misalignment | Effect | Use It In |
|---|---|---|
| loose plot + heavy emotion | calm image + emotional undertow; often the strongest scene type | mid-film breathing beat, before ending |
| tight plot + light emotion | tense event + lighter emotional surface | middle variation |
| tight plot + heavy emotion | peak intensity; cannot last too long | climax |
| loose plot + light emotion | pure breath | before or after climax |

Avoid:

- Both tracks staying low for too long; nothing happens and nothing is felt
- Both tracks staying high for too long; audience fatigue makes the climax ordinary
- Either track rising monotonically without release

## 4. Stretch And Snapback Inside A Scene

- **Stretch**: use repeated action, slower speech, and static image to build expectation
- **Snapback**: break the balance suddenly with a very short audiovisual action

## 5. Checklist

Phase 04 (scene list):

- [ ] Every scene has `plot_pace` (`loose` / `medium` / `tight`) and `emotion_pace` (`light` / `medium` / `heavy`)
- [ ] No more than two consecutive scenes share the same pacing state
- [ ] At least one plot/emotion misalignment exists

Phase 06 (script doctor):

- [ ] No single emotional state lasts longer than about three minutes
- [ ] High-emotion scenes have enough breathing room between them
- [ ] The all-is-lost beat before the climax gives the audience an emotional low point
