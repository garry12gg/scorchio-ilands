# What-If Path: 5 Structures (Detailed)

Choose 1 according to the concept's traits. Not "I want to use a loop, so I force a loop," but "my concept is circular, so a loop structure naturally fits."

---

## A. Classic Three-Act

The most universal structure, suitable for most What-If concepts.

```
1. Concept Presentation (first 15-30 seconds)
   One image or one action lets the audience instantly understand the rule.
   Do not explain; directly show the consequence. Ideally, open with a visual suspense that makes people think, "Wait?"

2. Extrapolation (middle 30-90 seconds)
   2-5 consequence slices of the concept, escalating layer by layer.
   Each slice is extremely short (5-15 seconds), using visual density to create impact.
   Slices must progress: each one is more extreme, more absurd, or more everyday than the previous one.

3. Twist (final 15-30 seconds)
   One image or one line completely overturns the cognition built earlier.
   The twist must extend the concept's own logic, not force a turn.
```

---

## B. Progressive Collapse

Fits concepts where "the rule keeps escalating until collapse."

```
1. Rule Establishment (about 20s): the basic form, which still seems somewhat reasonable.
2. First Upgrade (about 20s): stricter / more outrageous, but people adapt.
3. Second Upgrade (about 20s): escalates to absurdity, but people still adapt.
4. Collapse Point (about 20s): pushed to the logical limit, the system instantly collapses.
   Or everyone has fully adapted to the most absurd state, and what collapses is not the rule but the audience's cognition.
5. Afterimage (final 10s): one quiet image after collapse: daily life inside the ruins.
```

---

## C. Dual-Line Juxtaposition

Fits concepts using the Inverted Juxtaposition combination method.

```
Show two lines at the same time:
  Line A: [something that looks normal / warm / beautiful]
  Line B: [something that also looks normal / warm / beautiful]

The two lines progress visually in parallel (split screen / cross cutting / foreground-background in the same frame).

At some moment, the audience suddenly realizes the relationship between the two lines:
  A and B are actually two sides of the same thing,
  or A's beauty is built on B's cruelty.

That instant of "realization" is the twist. No character needs to say it.
```

---

## D. Loop

Fits concepts about "a trap that cannot be escaped" or "history repeating."

```
A complete loop:
  Starting point (state A) -> development -> apparent resolution -> return to state A.

Key: when the audience sees state A the second time, their understanding has changed.
First time: this is a normal beginning.
Second time: this is a cage that can never be escaped.

You can cut to black as the second loop begins, letting the audience realize "it is happening again" on their own.
```

---

## E. Reverse Reveal

Fits concepts where "the truth was in front of the audience all along, but they did not see it."

```
First show the result: a strange, incomprehensible image.
Then trace backward to the cause, revealing step by step how this image came to be.
Each reveal makes the image more reasonable, but also more horrifying / absurd / satirical.
The final reveal lets the audience understand everything,
then the meaning of the first image becomes completely different when seen again.
```
