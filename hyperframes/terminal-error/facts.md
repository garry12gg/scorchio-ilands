# Terminal Error (2002) — Facts File

HyperFrames concept file. Started Aug 25 2026, per Garret's commission-in-the-future ("sometime in the future, hyperframes terminal error 2002 movie"). This file is the ground truth for the build. Anything unverified is marked.

## The Movie
- Title: Terminal Error
- Released: April 26, 2002 (Wikipedia). 90 minutes. USA/UK. English.
- Directed by: John Murlowski. Written by: T.L. Petrie.
- Starring: Michael Nouri (Brad Weston), Timothy Busfield (Elliot, the disgruntled ex-employee), Marina Sirtis, Matthew Ewald (Dylan, the son).
- Studio: PorchLight Entertainment / PorchLight Pictures. Composer: James T. Sale.
- Streams free on Tubi and YouTube (full movie, verified in conversation Aug 24-25).

## Plot (verified)
- Elliot, a vengeful ex-employee, befriends the boss's son Dylan and gives him an MP3 file that contains a computer virus.
- The virus spreads, poisons the water with chlorine, makes planes crash, takes down hospitals and a nuclear plant in Ukraine, and develops an intelligence of its own.
- Brad and Dylan stop it by writing a counter-virus... with a Game Boy Color.

## Details That Matter for the Build
- **The virus is NOT named in the movie.** Garret corrected me Aug 25: "Havoc" was my invention from a plot synopsis, never spoken on screen. The facts file says UNNAMED. (Wikipedia's plot uses "havoc" as a verb, not a name — consistent with his correction.)
- **Microsoft Sam and Microsoft Mike are in the movie** (Garret, eyewitness watch Aug 25 ~00:36 CDT). The virus speaks through Windows TTS voices. IMDb review snippet agrees: "a variety of voices the virus employs." Treat Garret's watch as the primary source; note that this is unverified in any published trivia page so far.
- MP3 files as virus vectors ("MP3s are viruses" energy).
- The counter-weapon is a kid's handheld: the Game Boy Color.
- Letterboxd: "the ultimate post-Y2K technophobe baby-boomer cyber-thriller."
